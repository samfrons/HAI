# KoboToolbox

## What KoboToolbox is

KoboToolbox is a data collection and management platform widely used across the humanitarian and development sectors for surveys and field data collection. Its official documentation (support.kobotoolbox.org) serves as a knowledge base covering the whole lifecycle of a data collection project, organised around a Community Forum and a searchable set of guides. KoboToolbox is maintained by Kobo Inc.

## Main documentation areas

The support documentation is organised into eight primary sections:

1. Getting Started — account creation, quickstart guides, and terminology.
2. Account & Billing — authentication, account settings, and usage management.
3. Using the Formbuilder — form design with question types and skip logic.
4. Using XLSForm — spreadsheet-based form development, for authoring forms outside the visual builder.
5. Collecting Data — web forms, the KoboCollect mobile app, and GPS/media collection.
6. Managing Projects & Data — data viewing, validation, export, and permissions.
7. Analyzing Data — visualisation, reporting, and export to external analysis tools.
8. Integrations — API access and connections to Excel, Power BI, and GIS software.
